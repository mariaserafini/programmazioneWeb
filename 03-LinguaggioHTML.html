01 · sintassi

Il linguaggio HTML

HTML5 è la versione di riferimento del linguaggio. Ogni elemento HTML segue sempre la stessa sintassi:

<nome   attributo = "valore" > Contenuto </nome>
Tocca una parte qui sopra
Ogni elemento HTML strutturato è composto da queste parti fondamentali.
02 · struttura

Hello, World!

<!DOCTYPE html>
<html lang="it">
  <head>
    <meta charset="utf-8">
    <title>hello World Wide Web!</title>
  </head>
  <body>
    <!-- Contenuto della pagina -->
    <p>Hello, World!</p>
  </body>
</html>

Citazioni, abbreviazioni e codice

<blockquote> + <cite>

<blockquote> Talk is cheap. Show me the code. <cite>— Linus Torvalds</cite> </blockquote>
<mark>
Il Web connette persone oltre che computer.
Il Web connette <mark>persone</mark> oltre che computer.
<abbr>
Il W3C definisce gli standard web.

06 · collegamenti

Immagini e link

Il tag <img> serve per inserire delle immagini nel documento

<img   src="logo.png"   alt="Logo W3C" >
Tocca una parte qui sopra
<img> non racchiude testo ed è un elemento autocontenuto.

Il tag <a> serve per creare collegamenti ipertestuali (link)

<a href="https://w3.org" > W3C </a>
Tocca una parte qui sopra
L'attributo href determina dove viene reindirizzato l'utente.
