VS Code

Collega VS Code a GitHub

Niente plugin obbligatori: VS Code parla già con Git "di fabbrica". Serve solo installare Git sul computer (è un programma di sistema, non un'estensione).

Scarica da git-scm.com — è un programma del sistema operativo, non un'estensione di VS Code. Una volta installato, VS Code se ne accorge da solo e attiva l'icona Controllo Git nella barra laterale. Su PC scuola probabilmente c'è già.

L'unica estensione facoltativa è GitHub Pull Requests and Issues, utile solo per funzioni avanzate (Pull Request, Issue). Per push/pull/commit non serve.

Icona Account (in basso a sinistra) → Sign in with GitHub → autorizza dal browser. Va rifatto su ogni computer diverso, scuola e casa.

Ctrl/Cmd+Shift+P → Git: Clone → incolla l'URL del repository (da GitHub, bottone verde Code) → scegli dove salvare la cartella sul disco. Fallo una volta su ogni PC, scuola e casa.

File → Apri cartella e seleziona proprio la cartella appena clonata. È il passaggio che si dimentica più spesso: se lavori su una cartella diversa (es. sul Desktop, creata da zero), VS Code non ha idea che debba parlare con GitHub — il pannello Controllo Git resta vuoto o scollegato.

Inizio sessione → Pull (scarica quello che hai fatto sull'altro PC). Fine sessione → Commit + Push (carica su GitHub). Così l'altro computer troverà sempre l'ultima versione.
